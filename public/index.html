How it works — step by step

  • 1. Download & install: Tap Download below. On Android allow Install unknown apps → Allow once, then open the app.
  • 2. Register: Phone number + National ID + Driver's License + bike/car insurance photo.
  • 3. Get verified: Admin verifies within 24 hours. You'll get an SMS.
  • 4. Go Online & accept: Stay online near hostels. Tap Accept. Navigate to pickup, confirm pickup, deliver.
  • 5. Get paid: Fare + delivery fee splits 80-95% to you via M-Pesa automatically after delivery.

🎁 Surprise / Anonymous Gift orders — QR scan

If a sender orders as a surprise anonymous gift, you don't reveal the sender. On arrival, a QR code pops up on YOUR driver screen. Show it to the recipient. They scan it with any camera and see the secret message / video. Only after scan is the order marked delivered and you get paid.

Driver rule: Never tap "Delivered" before the recipient scans. If they can't scan, call support.

⚙️ How to download & install APK on Android (both apps)

  1. Tap the Download button above using Chrome. Keep WiFi on — Driver is 70MB, Vendor is 20MB.
  2. Open the downloaded file. Android will ask Allow install from unknown sources → tap Allow / Install anyway. This is normal because it's not from Play Store yet.
  3. Tap Install → Open. Allow Location + Notifications + Camera (needed for navigation & QR scan).
  4. Register with your Safaricom number for M-Pesa payouts. Riders add ID + License. Vendors add shop name + menu.
  5. Render tip: In your Render Static Site, add your APKs under public/apk/ so links /apk/dolce-driver-v1.0.apk work. Set header Content-Type: application/vnd.android.package-archive. Keep Drive mirror as backup because Render free tier can be slow for 70MB.
